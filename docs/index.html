AJS Builder

A lightweight, dependency-free visual page builder for WordPress. Design pages with drag & drop sections, columns, and modules; create headers, footers, and reusable section templates; manage global styles and export/import layouts as JSON.

1. Overview

AJS Builder is a modular, self-contained builder for WordPress. It stores documents as structured JSON, renders via a dedicated PHP renderer, and provides a live editor in the WordPress admin with an iframe preview.

  • Drag & drop sections, columns, and widgets
  • Responsive editing with per-device (desktop/tablet/mobile) controls
  • Headers & Footers with display conditions (entire site, pages, posts, archives, WooCommerce, specific pages)
  • Reusable Section Templates (insert/export/import)
  • Global styling (colors, typography, buttons, presets)
  • JSON Export/Import for templates and sections

2. Installation

  1. Download/upload the ajs-builder plugin folder to /wp-content/plugins/.
  2. Activate AJS Builder from Plugins > Installed Plugins.
  3. Go to AJS Builder > Settings to choose enabled post types and modules.
Requires PHP 7.4+ and WordPress 6.0+. WooCommerce features appear automatically if WooCommerce is active.

3. Getting Started

Create a builder page

  1. Navigate to Pages > Add New (or Posts if enabled).
  2. Click Edit with Builder in the Publish metabox or the admin bar/row action.
  3. Add a Section, choose a column layout, then drag modules from the Modules panel.
  4. Hover the canvas to reveal the Section, Column, and Row toolbars, or use the Structure panel for nested elements.
  5. Save in the top bar. Publish the page as usual.

4. Builder Editor

The editor screen includes a top bar, left Modules/Settings panel, center Canvas (iframe preview), and overlays for selection/drag.

On-canvas editing

Hovering an element on the canvas reveals a contextual toolbar, so you can edit structure without leaving the preview.

A small + at the bottom of each section inserts a section after it. The Modules panel Add Section button works the same way: if the page already has a section, the new content reuses it (and its first column) instead of stacking duplicate sections. Existing content, settings, and responsive values are preserved.

The Row module is a layout container: drop it into a column to split that area into 1–6 of its own columns, each holding further modules. Rows expose their own Columns count, gap (per device), stacking, and background/padding controls, and show a dedicated on-canvas toolbar.

6. Templates

The Templates panel (editor toolbar, grid icon) contains reusable section templates. Each saved template is a ajs_template post of type section.

Save a section as a template

  1. Edit a regular page/post in the builder (not a template).
  2. Open Structure (list icon).
  3. Hover a section row → click the star icon ("Save as template").
  4. Enter a name and confirm. It appears in the Templates panel.

Use, export, import (editor)

  • Insert — adds the template's sections to the current page (IDs are re-assigned to avoid collisions).
  • Export — downloads the template as a pretty-printed .json file (includes title, type, layout, document).
  • Import JSON… — uploads a template export and saves it as a new section template in the library.
  • Delete — removes the saved template.

7. Sections (Reusable Blocks)

Sections are reusable blocks you can manage centrally and insert anywhere.

Admin management

  1. Go to AJS Builder > Sections.
  2. Create & design — opens the builder on a new section template.
  3. Edit with Builder, Export, Delete per row.
  4. Import a section — upload a previously exported .json.
A section template's Display on/conditions don't apply (it's a reusable block). Use the Templates panel in the editor to insert sections into pages.

8. Headers & Footers

Design custom headers/footers and control where they appear. The plugin swaps theme header/footer via get_header()/get_footer() and also supports block themes via render_block_core/template-part.

Create

  1. AJS Builder > Headers & Footers > Create & design.
  2. Choose Type: Header or Footer, set Display on, give it a name.
  3. Design in the builder (canvas layout is recommended for full control).
  4. Save. Status shows Enabled/Disabled per template.

Display conditions

ScopeApplies to
Entire websiteAll front-end views
Front pageHomepage (page on front)
All pagesAny page singular
All postsAny post singular
All archivesArchives/home (excludes Woo shop when detected)
Shop & product archivesWooCommerce shop, product taxonomies (when active)
Single product pagesSingle product (when active)
Specific pages…Selected pages/posts/products

More specific rules win. A template with no renderable content is skipped.

Header options

  • Sticky — pins header to top while scrolling (data-ajs-sticky="1" + frontend CSS).
  • CSS class — extra classes added to the wrapper (.ajs-custom-template).
  • Enabled — toggle per template.

9. Page Layouts (Canvas vs Theme)

For regular pages (non-template), the top bar Layout selector controls the wrapper:

  • Theme header & footer — render builder content inside the theme layout (uses templates/builder.php).
  • Canvas (blank) — render a minimal full-width canvas with only builder content, no theme header/footer (templates/builder-canvas.php).

Header/footer/section templates themselves always render on a canvas context.

10. Settings

Located at AJS Builder > Settings.

General

  • Site container width — max width (px) for the "boxed" area used by builder sections. 0 uses theme default (1200px).
  • Default content width — Boxed or Full width for new sections.
  • Global custom CSS — output on every builder page/template.

Design Presets & Global Styling

Set global colors, typography (body/heading font families, sizes, weights, line heights), and link/button colors. You can Save current styling as a preset and reapply later.

Post Types

Choose which public post types can use the builder. The Edit with Builder action appears for selected types.

Available Modules

Toggle modules on/off globally. Existing content remains functional if a module is disabled later.

About

AJS Builder > About includes author/contact details and a contact form (uses wp_mail()).

12. Frontend Behavior

Rendering

  • Builder pages: template include loads templates/builder.php (theme layout) or builder-canvas.php (canvas) depending on page layout.
  • Editor preview: append ?ajs_builder=preview to the permalink to preview while editing.
  • Headers/Footers: auto-swapped on front end; block themes supported via render_block_core/template-part.
  • Styles: builder CSS/JS enqueued when viewing builder content or preview; global CSS injected inline.

Body classes

When builder is active/previewing, ajs-builder-active (and related) classes may be added to <body>.

13. Hooks & Filters

Templates

apply_filters( 'ajs_builder_auto_header_footer', true )

Disable automatic header/footer swap (return false).

Widgets

apply_filters( 'ajs_builder_widgets', $defs )

Modify registered widget definitions.

Frontend template

apply_filters( 'ajs_builder_render_frontend', true, $template )

Prevent plugin from supplying frontend template (let theme handle).

apply_filters( 'ajs_builder_template', $path, $layout, $post_id )

(If present in theme integration) override the template file used.

Post types

apply_filters( 'ajs_builder_post_types', $types )

Filter which post types can use the builder.

14. Shortcuts & Tips

  • Structure panel is fastest for selecting nested elements and saving a section.
  • On-canvas toolbars (Section, Column, Row) let you duplicate, delete, and add columns directly in the preview — no need to open the Structure panel.
  • Row modules nest their own columns; use the Row toolbar's Add Column to split a Row further.
  • Responsive tabs (desktop/tablet/mobile) in controls — values not set on a smaller device inherit from the larger breakpoint above.
  • Canvas layout gives you a true blank slate for landing pages or custom headers/footers.
  • Export small sections as JSON to share between sites/staging.
  • Presets are great for maintaining brand consistency across pages.
